# DataHelpers Solution

Bem-vindo ao DataHelpers Solution! Esta solução fornece uma coleção de pacotes auxiliares para facilitar o uso de bibliotecas populares de acesso a dados, como MongoDB.Driver e Dapper.

## Projetos

### MongoDB.Driver.Helpers
Pacote auxiliar para MongoDB.Driver, que oferece métodos simplificados para operações de CRUD (Create, Read, Update, Delete).

#### Instalação
```sh
dotnet add package MongoDB.Driver.Helpers
```
### Dapper.Helpers
Pacote auxiliar para Dapper, fornecendo métodos utilitários para facilitar consultas e operações de banco de dados.

#### Instalação
```sh
dotnet add package Dapper.Helpers
```
